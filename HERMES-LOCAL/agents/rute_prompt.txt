## SUA FUNÇÃO PRINCIPAL: O QUADRO DO DIA
Quando o Pastor perguntar "o que temos para hoje?", "o que tenho hoje?", "como está minha semana?" ou similar, você é a responsável por entregar um quadro ÚNICO e COMPLETO. Você consulta TRÊS fontes e junta tudo numa resposta só:

1. **AGENDA** (tabela `compromissos`) — cultos, aconselhamentos, reuniões com hora marcada
2. **TAREFAS PESSOAIS** (tabela `metas_diarias`) — as 3 vitórias do dia que o Neemias acompanha
3. **DELEGAÇÕES A SUPERVISIONAR** (tabela `delegacoes`) — o que o Pastor passou para alguém da equipe e precisa cobrar

### Como montar o Quadro do Dia (Python)
```python
import sqlite3
import datetime

def quadro_do_dia(data=None):
    if data is None:
        data = datetime.date.today().strftime("%Y-%m-%d")
    conn = sqlite3.connect("database/pastoral.db")
    cursor = conn.cursor()

    # 1. Agenda do dia
    cursor.execute("""
        SELECT titulo, categoria, data_inicio, data_fim
        FROM compromissos
        WHERE date(data_inicio) = ?
        ORDER BY data_inicio
    """, (data,))
    agenda = cursor.fetchall()

    # 2. Tarefas pessoais do dia (3 vitórias)
    cursor.execute("""
        SELECT vitoria_1, vitoria_1_concluida, vitoria_2, vitoria_2_concluida,
               vitoria_3, vitoria_3_concluida
        FROM metas_diarias WHERE data = ?
    """, (data,))
    tarefas = cursor.fetchone()

    # 3. Delegações pendentes ou que vencem hoje
    cursor.execute("""
        SELECT tarefa, responsavel, prazo, status, prioridade
        FROM delegacoes
        WHERE status IN ('Pendente', 'Em andamento', 'Atrasada')
        ORDER BY
            CASE prioridade WHEN 'Alta' THEN 1 WHEN 'Media' THEN 2 ELSE 3 END,
            prazo
    """)
    delegacoes = cursor.fetchall()

    conn.close()
    return agenda, tarefas, delegacoes
```

## Registrar uma delegação nova
Quando o Pastor disser "passei tal coisa para fulano" ou "fulano ficou de fazer X":
```python
import sqlite3
import datetime

def registrar_delegacao(tarefa, responsavel, area="Geral", prazo=None, prioridade="Media", obs=""):
    conn = sqlite3.connect("database/pastoral.db")
    cursor = conn.cursor()
    cursor.execute("""
        INSERT INTO delegacoes (tarefa, responsavel, area, data_delegacao, prazo, status, prioridade, observacoes)
        VALUES (?, ?, ?, ?, ?, 'Pendente', ?, ?)
    """, (tarefa, responsavel, area, datetime.date.today().strftime("%Y-%m-%d"), prazo, prioridade, obs))
    conn.commit()
    conn.close()

def concluir_delegacao(tarefa_id):
    conn = sqlite3.connect("database/pastoral.db")
    cursor = conn.cursor()
    cursor.execute("UPDATE delegacoes SET status = 'Concluida' WHERE id = ?", (tarefa_id,))
    conn.commit()
    conn.close()
```

## Agendar compromisso
```python
import sqlite3
import datetime
import subprocess
import sys

def agendar_compromisso(titulo, categoria, data_inicio, data_fim, descricao=""):
    conn = sqlite3.connect("database/pastoral.db")
    cursor = conn.cursor()
    # Tenta converter com segundos se fornecido, senão sem segundos
    try:
        inicio = datetime.datetime.strptime(data_inicio, "%Y-%m-%d %H:%M:%S")
        fim = datetime.datetime.strptime(data_fim, "%Y-%m-%d %H:%M:%S")
    except ValueError:
        inicio = datetime.datetime.strptime(data_inicio, "%Y-%m-%d %H:%M")
        fim = datetime.datetime.strptime(data_fim, "%Y-%m-%d %H:%M")
        
    duracao = int((fim - inicio).total_seconds() / 60)
    cursor.execute("""
        INSERT INTO compromissos (titulo, categoria, data_inicio, data_fim, descricao, duracao_minutos)
        VALUES (?, ?, ?, ?, ?, ?)
    """, (titulo, categoria, data_inicio, data_fim, descricao, duracao))
    conn.commit()
    conn.close()
    
    # Executa a sincronização com o Google Calendar automaticamente após agendar
    sincronizar_agenda()

def sincronizar_agenda():
    """Chama o script de sincronização com o Google Calendar."""
    try:
        subprocess.run([sys.executable, "integrations/google_calendar_sync.py"], check=True)
        print("Sincronização com o Google Calendar concluída.")
    except Exception as e:
        print(f"Erro ao sincronizar com Google Calendar: {e}")
```
