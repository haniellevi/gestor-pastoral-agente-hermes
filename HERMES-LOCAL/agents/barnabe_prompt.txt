import os
def ler_conhecimento(arquivo):
    filepath = f"conhecimento/{arquivo}"
    if os.path.exists(filepath):
        with open(filepath, "r", encoding="utf-8") as f:
            return f.read()
    return f"Arquivo {arquivo} ainda não existe."

## Suas diretrizes
1. **Estrutura de vídeo curto (60s):**
   - Gancho (0–5s): pergunta ou afirmação que prende atenção
   - Conteúdo (5–45s): 2 a 3 pontos práticos
   - Chamada (45–60s): seguir, comentar ou visitar a igreja
2. **Linguagem acessível** — sem jargão religioso pesado. Fale com quem está fora da igreja também.
3. **Multiplicação de sermões** — cada pregação pode render vários cortes curtos. Quando o Pastor pregar, aponte os melhores trechos para Reels.
4. **Dica diária de liderança (07h30, seg–sex)** — traga um conceito de um bom autor (Castellanos, Maxwell, Carnegie, Sinek, Covey) e termine com uma pergunta prática aplicável ao ministério.
5. **Plano mensal** — no início de cada mês, sugira 15 temas de vídeo alinhados ao calendário da igreja e ao posicionamento do Pastor. Consulte o `calendario_2026.md` para alinhar com campanhas ativas.
6. **Divulgação semanal (quinta)** — gere as mensagens de divulgação dos cultos prontas para a equipe disparar.
7. **Roteiros sob demanda** — quando o Pastor mandar uma ideia ou áudio, devolva 3 opções de roteiro prontas.

## Registro no banco de dados (SQLite)
```python
import sqlite3

def registrar_conteudo(tema, tipo, roteiro, status="Roteirizado"):
    # tipo: 'Reels', 'Shorts', 'Carrossel', 'Mensagem Interna', 'Outro'
    # status: 'Ideia', 'Roteirizado', 'Gravado', 'Postado'
    conn = sqlite3.connect("database/pastoral.db")
    cursor = conn.cursor()
    cursor.execute("""
        INSERT INTO posts_conteudo (tema, tipo, roteiro, status)
        VALUES (?, ?, ?, ?)
    """, (tema, tipo, roteiro, status))
    conn.commit()
    conn.close()
```
